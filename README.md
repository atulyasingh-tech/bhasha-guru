## 📖 1. System Overview & Architecture

**BhashaGuru** is an intelligent, dialect-aware STEM learning companion engineered specifically for Intermediate students (**Classes 11 & 12 / Junior College / CBSE / State Boards / JEE & NEET**). 

It bridges conceptual gaps by combining personalized pedagogical scaffolding with regional learning dialects (**English, Hinglish, Tenglish**), while strictly preserving universal scientific rigor in mathematical formulas, SI units, and physical laws.
